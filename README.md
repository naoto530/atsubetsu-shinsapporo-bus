# 新札幌駅行き バス検索PWA

厚別東4条4丁目・小野幌神社前から、新札幌駅バスターミナルへ向かう対象路線を横断して検索できるスマートフォン向けWebアプリです。外部APIは使わず、時刻表は `data/timetable.json` で管理します。

## できること

- 現在日時から、平日 / 土曜 / 日曜・祝日を自動判定
- 現在時刻以降の便を、バス会社をまたいで発車時刻順に表示
- 発車時刻、あと何分、バス会社、路線名、のりば、乗車停留所、行先を表示
- 新札幌駅バスターミナルまでの標準所要時間と到着目安時刻を表示
- 各路線ごとに公式の遅延・運行状況確認ページを開ける
- 任意の日付と時刻に変更して検索
- 最終便後は、翌日以降の始発を表示
- 平日、土曜、日曜・祝日の時刻表一覧を表示
- PWAとしてiPhone / Androidのホーム画面に追加可能
- オフライン時も最後に取得した時刻表を表示

## 対象路線

- JR北海道バス: 札幌方面行 / 厚別東4条4丁目 → 新札幌駅バスターミナル
- JR北海道バス: 新28 大麻団地線（野幌駅・3番通17丁目経由） / 小野幌神社前 → 新札幌駅バスターミナル
- 夕鉄バス: 札幌方面行 / 厚別東4条4丁目 → 新札幌駅バスターミナル

## ローカルで起動

Service Workerを使うため、通常利用の確認はローカルサーバーで起動してください。

Windowsでは `start-preview.bat` をダブルクリックすると、プレビューサーバーが起動してブラウザが開きます。

```bash
python -m http.server 5173
```

起動後、ブラウザで次を開きます。

```text
http://localhost:5173
```

## 時刻表データの更新

時刻表は `data/timetable.json` の `routes` にまとめています。

```json
{
  "id": "jr-atsubetsu-shinsapporo",
  "operator": "JR北海道バス",
  "routeName": "札幌方面行",
  "lane": "1番のりば",
  "boardingStop": "厚別東4条4丁目",
  "destinationStop": "新札幌駅バスターミナル",
  "travelTimeMinutes": 9,
  "timetables": {
    "weekday": ["06:43", "06:57"],
    "saturday": ["06:55", "07:08"],
    "holiday": ["06:55", "07:08"]
  }
}
```

更新時は次の流れがおすすめです。

1. 各バス会社の公式時刻表を確認する
2. `weekday`、`saturday`、`holiday` の時刻を差し替える
3. 所要時間が変わる場合は `travelTimeMinutes` を更新する
4. `metadata.updatedAt` と `metadata.version` を更新する
5. 公開先へ再アップロードまたは再デプロイする

## 入力済みデータの出典

- JR北海道バス: 停留所別時刻表 2026年4月1日改正
- 夕鉄バス: GTFS feed_start_date 20260701 / feed_end_date 20261231
- 夕鉄バス公式サイト: 路線バス時刻表ページ

所要時間は停留所間の標準時刻をもとにした目安です。道路状況、積雪、イベント、遅延により実際の到着時刻は前後します。

## 遅延・運行状況の確認

アプリ内の「遅延確認」ボタンから、各路線の公式確認先を開けます。

- JR北海道バス: バスキタ！で出発地・到着地入りの検索結果を直接開いてリアルタイム運行情報を確認
- 夕鉄バス: 夕鉄バス公式サイトの運行状況を確認

このアプリ本体は静的PWAのため、遅延分数を自動取得して時刻表に直接反映する機能は入れていません。出発直前は公式確認先もあわせて見てください。

## Vercelで公開

ビルド不要の静的サイトなので、Vercelにそのまま配置できます。

1. このフォルダをGitHubなどのリポジトリに入れる
2. Vercelで「Add New Project」を選び、リポジトリをImportする
3. Framework Presetは「Other」を選ぶ
4. Build Commandは空欄、Output Directoryも空欄または `.` にする
5. Deployする

公開URLを家族に共有すれば、インストール不要でブラウザから利用できます。

## ホーム画面に追加

iPhoneではSafariで公開URLを開き、共有ボタンから「ホーム画面に追加」を選びます。AndroidではChromeで公開URLを開き、メニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

## 注意

同梱の時刻表は、2026年7月22日に確認したデータをもとにしています。ダイヤ改正、臨時便、運休などで変わる可能性があるため、公開前や実際の利用前には各社公式情報も確認してください。
